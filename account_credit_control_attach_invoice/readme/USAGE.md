Once configured, the feature is fully automated. When you print a **Credit Control Summary** for a customer:

1.  The system generates the main credit control summary report as usual.
2.  It then identifies all open invoices included in the summary.
3.  For each invoice, it generates a PDF copy using the report format you selected during configuration.
4.  Finally, it merges the credit control summary and all individual invoice PDFs into a single, combined PDF file, ready for you to download or send.

The resulting file will present the credit control summary on the first page, followed by copies of each referenced invoice, simplifying the dunning process for both you and your customer.
