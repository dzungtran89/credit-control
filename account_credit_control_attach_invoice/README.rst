This module enhances the standard credit control process by allowing you
to attach a copy of the original invoices to the credit control summary
report.

When you send a payment reminder to a customer, this feature bundles the
summary with all relevant invoices into a single PDF file, making it
easier for your customer to review and process the payment. This helps
reduce customer queries and accelerates payment collection by providing
all necessary documents in one place.

Configuration
=============

To automatically attach invoices to credit control summaries, you must
first select the invoice report to be used.

1. Go to **Invoicing > Configuration > Settings**.
2. Under the **Credit Control** section, locate the **Report
   Attachment** option.
3. In the **Report to attach** field, choose the specific invoice report
   format you wish to send to customers (e.g., "Invoices").
4. Click **Save** to apply the new settings.

Usage
=====

Once configured, the feature is fully automated. When you print a
**Credit Control Summary** for a customer:

1. The system generates the main credit control summary report as usual.
2. It then identifies all open invoices included in the summary.
3. For each invoice, it generates a PDF copy using the report format you
   selected during configuration.
4. Finally, it merges the credit control summary and all individual
   invoice PDFs into a single, combined PDF file, ready for you to
   download or send.

The resulting file will present the credit control summary on the first
page, followed by copies of each referenced invoice, simplifying the
dunning process for both you and your customer.
